# Capturas de Tela por Case

Use esta pasta para anexar as imagens dos projetos.

## Convenção de nome

- Miniatura (capa): `cover.png`
- Home/Destino principal da landing: `hero-desktop.png` e `hero-mobile.png`
- Bloco de funcionalidades/serviços: `features-desktop.png`
- CTA e conversão (formulário/WhatsApp/contato): `cta-desktop.png`
- Página de detalhe/roteiro técnico: `detail-desktop.png`
- (Opcional) estado mobile completo: `full-mobile.png`

## Entrega sugerida

1. Salve as imagens com os nomes acima dentro de cada pasta do projeto.
2. Se houver variação por tamanho, mantenha as versões desktop e mobile separadas.
3. Se algum projeto for repositório privado sem tela pública, envie prints da documentação, arquitetura e do repositório/local run.
